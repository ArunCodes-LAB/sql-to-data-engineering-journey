# SQL to Data Engineering Journey

> Learning journey from SQL basics to a complete data engineering pipeline.

## Student Records SQL Project

This project demonstrates how to create a student database, insert records, identify missing values, and update them with SQL.

## What the script does

1. Creates the `student_record_db` database.
2. Creates the `students_Records` table.
3. Inserts eight student records.
4. Fills missing phone numbers.
5. Fills missing grades.
6. Displays the final updated table.

## Run the project

Open [`students.sql`](students.sql) in MySQL Workbench or another MySQL client and run the statements in order.
